# Dungeon Game — COMP302 Project

A **Java-based dungeon game** developed as part of the **COMP302 Software Engineering** course.

The project focuses on object-oriented software design, game mechanics, and building a structured interactive application in Java.

---

## About the Project

The game is designed around a dungeon-based environment where the player interacts with different game elements and progresses through the gameplay.

The project was developed collaboratively and applies software engineering concepts such as:

- Object-oriented programming
- Modular design
- Game state management
- Event-driven interactions
- Reusable components
- Team-based software development

---

## Technologies

- Java
- Object-Oriented Programming
- Java GUI / Graphics

## Running the Project

### 1. Clone the repository

```bash
git clone https://github.com/byilmaz20/dungeon-engineers
```

### 2. Open the project

Open the repository using a Java-compatible IDE such as:

- IntelliJ IDEA
- Eclipse
- Visual Studio Code

### 3. Configure Java

Make sure a compatible Java Development Kit (JDK) is installed.

Check your Java version:

```bash
java -version
```

### 4. Run the game

Run the application's main Java class from your IDE.

## Main Concepts

The project demonstrates several important software engineering principles:

### Object-Oriented Design

Game components are represented using Java classes and objects, allowing responsibilities to be separated into reusable components.

### Game Logic

The application manages player interactions, game progression, and the state of the dungeon.

### Save System

The repository includes a `Saves` directory for storing game-related save data.

### Modular Structure

Source files, external libraries, and game data are separated into different directories to keep the project organized.
